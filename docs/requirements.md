# scanet - 要件定義書

## 1. プロジェクト概要

### 1.1 目的
LAN内のデバイスを高速にスキャンし、ターミナル上で視覚的に表示するTUIツールを開発する。

### 1.2 背景
ネットワーク管理やトラブルシューティングにおいて、LAN内のデバイスを素早く把握することは重要である。既存のツール（nmap, arp-scan等）は高機能だが、リアルタイムでの可視化やTUIでの操作性に欠ける場合がある。本ツールは、Rustの高速性を活かし、使いやすいTUIインターフェースでデバイス情報を提供する。

### 1.3 ターゲットユーザー
- ネットワーク管理者
- 開発者
- セキュリティ担当者
- 自宅ネットワークの管理を行う一般ユーザー

### 1.4 対応プラットフォーム
- macOS
- Linux

## 2. 機能要件

### 2.1 デバイス検出機能

#### 2.1.1 スキャン方式
| 方式 | 説明 | 特徴 |
|------|------|------|
| Pingスキャン | ICMPエコー要求を送信して検出 | 権限不要だがファイアウォールでブロックされる可能性 |

- システムのpingコマンドを使用
- 並列実行（同時50接続）による高速スキャン
- タイムアウト: 500ms

#### 2.1.2 IPアドレス範囲指定
| 指定方法 | 例 | 説明 |
|----------|-----|------|
| CIDR表記 | `192.168.1.0/24` | サブネット全体を指定 |
| 範囲指定 | Start IP / End IP | 開始〜終了IPを指定 |
| 自動検出 | （デフォルト） | 現在のネットワークインターフェースからサブネットを自動取得 |

#### 2.1.3 MACアドレス取得
- システムのARPテーブルから取得
- スキャン開始時にARPテーブルをキャッシュ
- キャッシュにない場合はリトライ付きで再取得
- **注意**: 同一サブネット内のデバイスのみ取得可能（ARP仕様）

### 2.2 デバイス情報表示

検出したデバイスについて、以下の情報を表示する：

| 項目 | 説明 | 取得方法 |
|------|------|----------|
| IPアドレス | デバイスのIPv4アドレス | スキャン結果 |
| MACアドレス | デバイスの物理アドレス | ARPテーブル |
| ホスト名 | デバイスのホスト名 | 逆引きDNS |
| ベンダー名 | NICの製造元 | MACアドレスからOUI lookup |
| 応答時間 | pingの応答時間 | スキャン時に計測 |

#### 2.2.1 ベンダー名取得
1. ローカルOUIデータベース（mac_oui crate）から検索
2. 見つからない場合、詳細画面表示時にオンラインAPI（macvendors.com）で検索

### 2.3 リアルタイム更新

| 機能 | 説明 |
|------|------|
| 連続モード | `c`キーでON/OFF切り替え |
| 自動再スキャン | 連続モード時、設定した間隔で定期的にスキャンを実行 |
| 更新間隔設定 | `+`/`-`キーで秒単位で調整可能（デフォルト: 10秒） |
| 新規デバイスハイライト | 新しく検出されたデバイスを視覚的に強調表示 |

### 2.4 TUI機能

#### 2.4.1 画面構成
```
┌─────────────────────────────────────────────────────────────┐
│ scanet - LAN Device Scanner                 [192.168.1.0/24] │
├─────────────────────────────────────────────────────────────┤
│ IP Address     │ MAC Address       │ Hostname    │ Vendor   │
│────────────────│───────────────────│─────────────│──────────│
│ 192.168.1.1    │ AA:BB:CC:DD:EE:FF │ router      │ Cisco    │
│ 192.168.1.10   │ 11:22:33:44:55:66 │ desktop-pc  │ Apple    │
│ 192.168.1.25   │ 77:88:99:AA:BB:CC │ iphone      │ Apple    │
│ ...                                                          │
├─────────────────────────────────────────────────────────────┤
│ Devices: 15 │ Last scan: 10s ago │ [S]can [C]ontinuous [Q]uit │
└─────────────────────────────────────────────────────────────┘
```

#### 2.4.2 操作方法
| キー | 動作 |
|------|------|
| `↑` / `↓` または `j` / `k` | デバイス選択 |
| `Enter` | 選択デバイスの詳細表示 |
| `s` | 手動スキャン実行 |
| `c` | 連続モードのON/OFF切り替え |
| `r` | 範囲指定画面を開く |
| `+` / `-` | スキャン間隔の増減（連続モード時） |
| `?` | ヘルプ表示 |
| `q` | 終了 |

#### 2.4.3 詳細表示画面
デバイスを選択してEnterを押すと、詳細情報を表示：
- IPアドレス
- MACアドレス
- ホスト名
- ベンダー名（不明の場合はオンライン検索を実行）
- 応答時間

#### 2.4.4 範囲指定画面
- CIDR表記または開始IP/終了IPで範囲を指定
- Tabキーでフィールド切り替え
- 矢印キーでカーソル移動

## 3. 非機能要件

### 3.1 パフォーマンス
- /24ネットワーク（254ホスト）のスキャンを数秒で完了
- 並列スキャン（50同時接続）による高速化
- OUIデータベースは起動時に一度だけロード

### 3.2 信頼性
- スキャン失敗時の適切なエラーハンドリング
- ネットワーク未接続時の明確なメッセージ表示

### 3.3 ユーザビリティ
- 直感的なキーボード操作（Vim風キーバインド対応）
- 視覚的にわかりやすい表示
- ヘルプ機能の充実
- スキャン進捗のリアルタイム表示

### 3.4 セキュリティ
- ローカルネットワークのみを対象
- 特別な権限不要（システムpingコマンドを使用）

## 4. 技術スタック

| カテゴリ | 技術 | 用途 |
|----------|------|------|
| 言語 | Rust | メイン開発言語 |
| TUIフレームワーク | ratatui | ターミナルUI構築 |

| HTTP | reqwest | オンラインベンダー検索API呼び出し |
| ローカルIP取得 | local-ip-address | 現在のIPアドレス取得 |
| エラーハンドリング | anyhow | エラー処理の簡素化 |

## 6. 用語集

| 用語 | 説明 |
|------|------|
| ARP | Address Resolution Protocol。IPアドレスからMACアドレスを解決 |
| OUI | Organizationally Unique Identifier。MACアドレスの上位24ビット |
| CIDR | Classless Inter-Domain Routing。IPアドレスの表記法 |
| TUI | Text User Interface。テキストベースのユーザーインターフェース |
| TTL | Time To Live。パケットの生存時間 |
